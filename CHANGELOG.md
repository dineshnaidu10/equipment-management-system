# Changelog

## [1.0.0] - 2026-10-10
First public release (corresponds to internal version v12).

### Features
- Dashboard with KPI cards, maintenance alerts and low-stock alerts
- Maintenance tracker with completion logging, history and Excel export
- Maintenance calendar (monthly view, colour-coded by urgency)
- Bulk task completion (multi-select)
- Parts usage recorded on task completion, with automatic stock deduction
- Equipment registry with attachments
- Spare parts inventory with check-in / check-out and transaction history
- Reorder list (grouped by supplier) with Excel export
- Documents library with tags
- Export Centre (maintenance history, task status, inventory, transactions, reorder list, full system export)
- Right-click context menus and double-click-to-edit on all main tables
- Excel-driven configuration (`ems_config.xlsx`), auto-generated on first run
- SQLite with WAL mode
